# Ask Ellen AI

A conversational AI assistant built for Ellen Lee's portfolio. Visitors can ask about her projects, 
skills, background, and experience — and get instant, personalized answers.

## Built with
- Google Gemini API (free tier)
- Vanilla HTML, CSS, JavaScript
- No frameworks, no dependencies

## How to use
1. Open `index.html` via any static host (Netlify, GitHub Pages, etc.)
2. The AI is ready to go — no setup needed for visitors
